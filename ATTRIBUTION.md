# Attribution

## Inspiration

This extension was inspired by [ocfox/nixpkgs-tracker](https://github.com/ocfox/nixpkgs-tracker)
and its direct GitHub API approach to tracking Nixpkgs pull requests across branches.
The Raycast interface, authentication integration and extension implementation are
developed independently for this project.
